# Copper

Copper accents on deep charcoal, warm greys, and a paper-and-ink light variant. No neon, no cold blues; borders you can actually see and contrast that stays comfortable after hours in the editor.

Two themes ship in this extension:

- **Copper** (dark)
- **Copper Light**

The markdown preview is styled to match.

Copper started as a terminal palette and grew into a small family: matching ghostty, starship and zsh colours live at [k0x3k/copper-theme](https://github.com/k0x3k/copper-theme).
